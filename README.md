# MiniMax H3 Image Prompts

An Agent Skill from AI H3 Image for writing and revising image prompts from a brief. It handles new images, exact on-image text, and reference edits. Start with the [MiniMax H3 Image Prompts gallery](https://aih3image.com/minimax-h3-prompts) for visual examples.

## Install

```bash
npx skills add airobushotpot/minimax-h3-image-prompts --skill minimax-h3-image-prompts
```

Ask your agent to use the Skill with a real brief. For example, ask it to turn a product idea into a 4:5 hero image prompt with clear space for a headline, or give it a reference photo and tell it which details to preserve.

The Skill returns text for use in your image generator. Its instructions and original examples are available under the [MIT-0 license](LICENSE).
